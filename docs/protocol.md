# 本地协议 v1

Unix stream socket，一次连接一个请求和一个响应，无压缩。整数使用无符号
32 位小端序。客户端读取完整响应后关闭连接；不依赖 EOF 作为消息边界。

## 请求

| 偏移 | 长度 | 内容 |
| --- | --- | --- |
| 0 | 8 | ASCII `SOCR0001` |
| 8 | 4 | width，必须大于零 |
| 12 | 4 | height，必须大于零 |
| 16 | 4 | RGB 字节数，必须等于 width × height × 3 |
| 20 | 变长 | 顶部向下、左到右的紧凑 RGB888，无 alpha、无行填充 |

像素数据上限 64 MiB，乘法须检查溢出。不合法帧关闭连接；服务保持运行。

## 响应

| 偏移 | 长度 | 内容 |
| --- | --- | --- |
| 0 | 8 | ASCII `SOCR0001` |
| 8 | 4 | status：0 成功，1 后端失败 |
| 12 | 4 | 文本字节数，上限 1 MiB |
| 16 | 变长 | 无 NUL 的 UTF-8；成功时为识别文本，失败时为错误说明 |

成功的零长度文本表示没有文字，不触发原生识别回退。
行之间使用 LF，注入层也接受 CRLF；空行被略过，行内空格保留。
当前可信的 Rust 服务保证 UTF-8，C++ 客户端检查 NUL 与长度，未独立校验 UTF-8。

客户端在连接和收发阶段读取 `spectacle-ocrrc` 中的 `OCR/TimeoutMs`，
默认使用 20000 ms 总截止时间；`SPECTACLE_OCR_TIMEOUT_MS` 可覆盖为 100–25000 ms。Rust 服务采用 3 秒单次读写超时；
尚未实现服务端整帧总截止时间或并行客户端调度。真实 OCR 在文本行之间检查
15 秒处理预算，但不能中途打断单次 ONNX 推理。服务应置于用户私有目录，
socket 权限 0600。启动器创建 0700 的临时目录并管理其生命周期。

后续如需文本框、置信度、语言或取消请求，另行定义版本，不改变 v1 字段含义。
